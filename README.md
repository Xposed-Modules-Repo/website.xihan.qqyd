## QQ 阅读 Xp 模块

### 功能

* 去广告
* 激励视频

### 注意事项

* 安装后在 LSPosed 中启用模块，作用域勾选 **QQ 阅读**，然后重启 QQ 阅读。
* 设置页面在：**QQ 阅读 → 我的 → 设置 → QQ 阅读模块设置**，就在“兑换中心”上面。
* 修改配置后重启 QQ 阅读完整生效。
* 需要支持原生模块的新版 LSPosed，目前仅提供 **arm64-v8a** 版本。
* 不要与旧 QQ 阅读模块同时启用，避免冲突。

### 支持版本

* 已验证：**QQ 阅读 8.5.6.888（423）**。
* 作用域：`com.qq.reader`。
* 其他版本暂未验证，不保证所有广告和激励场景都生效。

### 模块下载

* [Releases](https://github.com/Xposed-Modules-Repo/website.xihan.qqyd/releases)

### 常见问题

* **找不到模块设置？**

  检查模块是否启用、作用域是否勾选，以及 QQ 阅读版本是否符合上述范围，然后彻底关闭 QQ 阅读再打开。

* **开关改了没效果？**

  重启 QQ 阅读后再试。

* **激励视频结束了，但是奖励没到账？**

  客户端流程结束不代表服务端奖励一定到账，以实际结果为准。
